# 桌面端集成案例研究

> 状态：这是基于 Pi SDK/RPC 的推测性产品集成案例，不是 Pi 已发布的桌面端产品或官方路线图。

## 可以讨论的架构

桌面壳可以把 UI、受限宿主进程和 Pi 引擎分离。UI 负责显示；宿主进程负责授权、凭据和窗口生命周期；引擎进程负责通过 SDK 或 RPC 运行 Pi。进程分离通常比把所有能力暴露给渲染层更容易建立安全边界。

## 必须先验证的事项

- SDK 和 RPC 的版本兼容性。
- cwd、会话目录和凭据的隔离范围。
- 文件写入、终端工具和网络连接的确认界面。
- stdout 协议与诊断日志的分流。
- 退出、恢复和压缩时的会话一致性。
