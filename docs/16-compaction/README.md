# 会话压缩与上下文管理

> 当对话过长时，Pi 通过压缩机制释放上下文空间，保持会话连贯。

---

## 一、压缩概览

### 1.1 什么是压缩？

压缩是将旧消息总结为摘要，同时保留最近消息的过程。这释放了上下文窗口空间，让对话可以继续。

### 1.2 压缩触发时机

| 触发方式 | 说明 |
|----------|------|
| **自动压缩** | 上下文接近窗口限制时自动触发 |
| **手动压缩** | 使用 `/compact` 命令 |
| **分支摘要** | 使用 `/tree` 切换分支时 |

---

## 二、自动压缩

### 2.1 触发条件

```
contextTokens > contextWindow - reserveTokens
```

默认 `reserveTokens` 为 16384 tokens。

### 2.2 压缩过程

1. **查找切割点**：从最新消息向前遍历，累积 token 估算直到达到 `keepRecentTokens`（默认 20k）
2. **提取消息**：收集从上次保留边界到切割点的消息
3. **生成摘要**：调用 LLM 生成结构化摘要
4. **附加条目**：保存 `CompactionEntry`，包含摘要和 `firstKeptEntryId`
5. **重载会话**：使用摘要 + 从 `firstKeptEntryId` 开始的消息

### 2.3 配置

```json
{
  "compaction": {
    "enabled": true,
    "reserveTokens": 16384,
    "keepRecentTokens": 20000
  }
}
```

## 三、手动压缩

### 3.1 基本使用

```
/compact
```

### 3.2 自定义焦点

```
/compact 重点关注性能优化
/compact 只保留代码修改相关的上下文
```

### 3.3 使用场景

- 上下文即将用尽
- 对话主题切换
- 需要聚焦特定方面

---

## 四、分支摘要

### 4.1 什么是分支摘要？

当 `/tree` 切换分支时，Pi 可以摘要被放弃的分支，保留重要上下文。

### 4.2 使用方式

1. 在 `/tree` 中选择要切换到的条目
2. Pi 提示是否摘要当前分支
3. 选择摘要方式：
   - 不摘要
   - 使用默认提示摘要
   - 使用自定义焦点摘要

### 4.3 配置

```json
{
  "branchSummary": {
    "reserveTokens": 16384,
    "skipPrompt": false
  }
}
```

`skipPrompt: true` 跳过摘要提示，默认不摘要。

---

## 五、压缩策略

### 5.1 结构化摘要

压缩生成的摘要包含：

| 部分 | 说明 |
|------|------|
| **对话摘要** | 整体对话内容总结 |
| **文件操作** | 累积的文件读写操作 |
| **关键决策** | 重要的技术决策 |
| **当前状态** | 当前的工作状态 |

### 5.2 迭代压缩

如果已有摘要，新摘要会基于旧摘要生成，保持连贯性。

---

## 六、上下文管理最佳实践

### 6.1 预防上下文溢出

1. **定期压缩**：长对话时定期使用 `/compact`
2. **聚焦话题**：避免话题过于发散
3. **使用分支**：不同话题使用 `/fork` 创建分支

### 6.2 压缩后验证

压缩后检查：
- 关键信息是否保留
- 文件操作历史是否完整
- 当前任务状态是否正确

### 6.3 自定义压缩

通过扩展自定义压缩行为：

```typescript
pi.on("session_compact", async (event, ctx) => {
  // 自定义压缩逻辑
  // event.messages - 要压缩的消息
  // event.previousSummary - 之前的摘要
});
```

## 八、性能考虑

### 8.1 Token 估算

Pi 使用启发式方法估算 token 数量，不是精确计算。

### 8.2 压缩开销

压缩需要调用 LLM 生成摘要，会消耗 token 和时间。

### 8.3 优化建议

- 设置合理的 `keepRecentTokens`（默认 20k）
- 对于简单任务，可以关闭自动压缩
- 使用 `reserveTokens` 留足响应空间

## 九、小结

| 功能 | 说明 |
|------|------|
| **自动压缩** | 上下文接近限制时自动触发 |

| **结构化摘要** | 包含对话、文件操作、决策 |
