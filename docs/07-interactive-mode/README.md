# 交互模式详解

> 掌握 Pi 的交互模式，高效使用编辑器、命令和快捷键。

---

## 一、界面布局

```
┌─────────────────────────────────────────────────────────────┐
│  启动头：快捷键、加载的 AGENTS.md、技能、扩展                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  消息区域：用户消息、助手回复、工具调用、通知                      │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  编辑器：输入区域，边框颜色表示思考级别                           │
├─────────────────────────────────────────────────────────────┤
│  页脚：工作目录、会话名、Token 用量、费用、当前模型                │
└─────────────────────────────────────────────────────────────┘
```

## 二、编辑器功能

### 2.1 文件引用

| 功能 | 操作 |
|------|------|
| 模糊搜索文件 | 输入 `@` |
| 路径补全 | 输入路径后按 Tab |
| 命令行引用文件 | `pi @README.md "总结"` |

### 2.2 多行输入

- **Shift+Enter**：换行（macOS/Linux）
- **Ctrl+Enter**：换行（Windows Terminal）

### 2.3 图片输入

- **Ctrl+V**：粘贴图片（Alt+V on Windows）
- **拖拽**：将图片拖到终端

### 2.4 Shell 命令

| 命令 | 说明 |
|------|------|
| `!command` | 执行命令，输出发送给 LLM |
| `!!command` | 执行命令，不发送输出 |

示例：
```
!npm run lint          # 执行 lint 并让 LLM 分析结果
!!git status           # 查看 git 状态，不发送给 LLM
```

### 2.5 外部编辑器

按 **Ctrl+G** 打开 `$VISUAL` 或 `$EDITOR` 设置的外部编辑器。

## 三、斜杠命令

在编辑器中输入 `/` 触发命令补全。

### 3.1 会话管理

| 命令 | 说明 |
|------|------|
| `/new` | 开始新会话 |
| `/resume` | 浏览并选择历史会话 |
| `/session` | 显示当前会话信息 |
| `/name <名称>` | 设置会话显示名 |
| `/tree` | 导出会话树 |
| `/fork` | 从之前的消息创建新会话 |
| `/clone` | 复制当前分支到新会话 |

### 3.2 模型与设置

| 命令 | 说明 |
|------|------|
| `/model` | 切换模型 |
| `/scoped-models` | 管理 Ctrl+P 循环的模型 |
| `/settings` | 打开设置界面 |
| `/login` | OAuth 登录 |
| `/logout` | 退出登录 |

### 3.3 上下文管理

| 命令 | 说明 |
|------|------|
| `/compact [指令]` | 手动压缩上下文 |
| `/reload` | 重新加载扩展、技能、提示词 |

### 3.4 输出

| 命令 | 说明 |
|------|------|
| `/copy` | 复制最后一条助手消息 |
| `/export [文件]` | 导出会话为 HTML |
| `/share` | 上传为 GitHub Gist |

### 3.5 其他

| 命令 | 说明 |
|------|------|
| `/hotkeys` | 显示所有快捷键 |
| `/changelog` | 显示版本历史 |
| `/quit` | 退出 Pi |

## 四、快捷键

### 4.1 常用快捷键

| 快捷键 | 说明 |
|--------|------|
| Ctrl+C | 清空编辑器 |
| Ctrl+C 两次 | 退出 Pi |
| Escape | 取消/中止 |
| Escape 两次 | 打开 `/tree` |
| Ctrl+L | 打开模型选择器 |
| Ctrl+P / Shift+Ctrl+P | 循环切换模型 |
| Shift+Tab | 循环切换思考级别 |
| Ctrl+O | 折叠/展开工具输出 |
| Ctrl+T | 折叠/展开思考块 |

### 4.2 完整快捷键列表

运行 `/hotkeys` 查看所有快捷键。

## 五、消息队列

在 Agent 工作时，你可以提交消息：

| 操作 | 说明 |
|------|------|
| **Enter** | 排队"引导消息"，当前工具调用完成后发送 |
| **Alt+Enter** | 排队"后续消息"，Agent 完成所有工作后发送 |
| **Escape** | 中止，恢复排队消息到编辑器 |
| **Alt+Up** | 将排队消息取回编辑器 |

### 5.1 引导消息 vs 后续消息

- **引导消息**（Enter）：在当前回合结束后立即发送，用于引导 Agent 的下一步操作
- **后续消息**（Alt+Enter）：等待 Agent 完成所有工作后发送，用于追加新任务

### 5.2 配置消息传递

在 `settings.json` 中配置：

```json
{
  "steeringMode": "one-at-a-time",  // "all" 或 "one-at-a-time"
  "followUpMode": "one-at-a-time"   // "all" 或 "one-at-a-time"
}
```

## 六、思考级别

Pi 支持不同的思考级别，影响 LLM 的推理深度：

| 级别 | 说明 |
|------|------|
| `off` | 不显示思考过程 |
| `minimal` | 最小思考 |
| `low` | 低度思考 |
| `medium` | 中等思考（默认） |
| `high` | 高度思考 |
| `xhigh` | 极高思考 |

切换方式：
- **Shift+Tab**：循环切换
- `/settings`：在设置中选择
- `--thinking <级别>`：启动时指定

---

## 七、模型切换

### 7.1 打开模型选择器

- **Ctrl+L**：打开模型选择器
- `/model`：同上

### 7.2 快速循环

- **Ctrl+P**：切换到下一个模型
- **Shift+Ctrl+P**：切换到上一个模型

### 7.3 配置循环模型

在 `settings.json` 中配置：

```json
{
  "enabledModels": ["claude-*", "gpt-4o", "gemini-2*"]
}
```

或使用 `/scoped-models` 在交互中管理。

---

## 八、工具输出

### 8.1 折叠/展开

- **Ctrl+O**：折叠/展开工具输出
- **Ctrl+T**：折叠/展开思考块

### 8.2 默认折叠

在 `settings.json` 中配置工具输出的默认折叠行为：

```json
{
  "treeFilterMode": "no-tools"  // 默认折叠工具输出
}
```

---

## 九、自定义设置

### 9.1 通过 /settings

输入 `/settings` 打开设置界面，可以修改：
- 思考级别
- 主题
- 消息传递模式
- 传输方式

### 9.2 通过 JSON 文件

编辑 `~/.pi/agent/settings.json`（全局）或 `.pi/settings.json`（项目级）。
